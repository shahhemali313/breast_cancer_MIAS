# Breast Cancer Detection using MIAS Dataset

## Overview
This project focuses on the detection and classification of breast cancer using 
the **MIAS (Mammographic Image Analysis Society) dataset**. The system applies 
image preprocessing, feature extraction, and Machine Learning / Deep Learning 
techniques to improve diagnostic accuracy in mammogram-based cancer detection.

The project is designed to demonstrate an **end-to-end AI pipeline** for medical 
image analysis, from raw data preprocessing to model evaluation.

---

## Dataset
- **MIAS Dataset (Mammographic Image Analysis Society)**
- Contains labeled mammogram images (normal, benign, malignant)
- Widely used benchmark dataset for breast cancer research

> Dataset access instructions are provided in the repository (not included 
directly due to licensing restrictions).

---

## Key Features
- Mammogram image preprocessing and enhancement
- Noise reduction and filtering techniques
- Feature extraction from medical images
- Machine Learning and Deep Learning-based classification
- Performance evaluation using standard medical metrics

---

## Methodology
1. **Data Preprocessing**
   - Image resizing and normalization
   - Contrast enhancement and noise removal
   - Region of Interest (ROI) extraction

2. **Feature Extraction**
   - Texture-based and statistical features
   - Optional deep feature extraction using CNNs

3. **Model Development**
   - Machine Learning models (SVM, Random Forest, KNN, Logistic Regression)
   - Deep Learning models using CNN architectures

4. **Evaluation Metrics**
   - Accuracy
   - Precision
   - Recall (Sensitivity)
   - F1-score
   - ROC-AUC
